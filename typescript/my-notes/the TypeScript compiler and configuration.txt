Compiling individual files 

tsc filename.tsc


Go to the root project directory 

{
  "compilerOptions": {
    "target": "es2023",
    "module": "nodenext",
    "moduleResolution": "nodenext",
    "rootDir": "./src",
    "outDir": "./dist",
    "strict": true,
    "sourceMap": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["src/**/*"]
}

TO compile the all the files from the source / project root directory  
$: npx tsc 

To Run: 
node /dist/<filename.js>

To run the file directly 
npm start dist/dsa/ds/1.arrays.js
