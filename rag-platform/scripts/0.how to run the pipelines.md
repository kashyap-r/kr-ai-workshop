Delete the exisitn data first 

rm -rf data/processed/parsed/ZCompanyLLC
rm -rf data/processed/chunks/ZCompanyLLC
rm -f data/processed/metadata/parsed_documents.jsonl
rm -f logs/ingestion.log
rm -f logs/chunking.log

Step 1: Run:
python scripts/ingest_documents.py
OR 
uv run python scripts/ingest_documents.py

Check:
data/processed/parsed/ZCompanyLLC/
data/processed/metadata/parsed_documents.jsonl
logs/ingestion.log

Step 2: Run 
uv run python scripts/chunk_documents.py

Check: 
data/processed/chunks/ZCompanyLLC/
logs/chunking.log

Step 3: To create the embeddings and vector store and persist the embeddings
Run 
uv run --project python python scripts/3.embed_and_index.py


Step 4: Query test 
uv run --project python python scripts/4.query_vector_store.py



At this point the end-to-end retrieval path: 
Raw HR corpus
    ↓
FilesystemConnector
    ↓
Parser
    ↓
ParsedDocument
    ↓
RecursiveChunker
    ↓
DocumentChunk
    ↓
BGE-small
    ↓
384-dim embeddings
    ↓
ChromaVectorStore
    ↓
Query embedding
    ↓
Top-K retrieval
    ↓
RetrievalResult
