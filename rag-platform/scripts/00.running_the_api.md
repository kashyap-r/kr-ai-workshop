### 1. Run the API

From: rag-platform/

run: uv run uvicorn rag_platform.api:app --reload

You should see something like:
Uvicorn running on http://127.0.0.1:8000

Then open:
http://127.0.0.1:8000/docs

FastAPI should give you Swagger UI.

### 2. Test /health
curl http://127.0.0.1:8000/health

Expected:
{"status":"ok"}

### 3. Test the actual RAG query
curl -X POST "http://127.0.0.1:8000/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "How many days can an employee based in India work remotely each week?",
    "top_k": 5
  }'

  Expected Output:

### 4. Test the API - E2E

In Terminal 1, Start the server: 
uv run uvicorn rag_platform.api:app --reload

In Terminal 2, Run 
curl -X POST http://127.0.0.1:8000/query \
  -H "Content-Type: application/json" \
  -d '{"query":"What is the company policy for working from home?","top_k":5}'

This basically tests the end to end path: 

HTTP
 ↓
FastAPI
 ↓
QueryService
 ↓
DenseRetriever
 ↓
BGE embedding
 ↓
Chroma
 ↓
Top 5 chunks
 ↓
JSON

Expected Output: You should get the Chunks from the HR Corpus..!!
