# Leave Application Rules

1. Check the employee profile for base location and employment status.
2. Check the current assignment/travel status in the employee record.
3. Determine the applicable jurisdiction using `global_jurisdiction_policy.md`.
4. Retrieve the policy and holiday calendar for that jurisdiction.
5. Check the employee leave record for available balance and existing bookings.
6. Check the contract for special leave entitlements, blackout periods, or approval requirements.
7. Check HR notes for PIP-related or business-critical approval requirements.
8. For extended leave, confirm all required approval levels before treating the leave as approved.

## Important
A leave request being *eligible to be submitted* is not the same as being *approved*.
