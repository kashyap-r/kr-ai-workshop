The test scripts will eventually. be organised in the below directory structure. 

tests/
├── unit/
├── integration/
├── contract/
├── retrieval/
├── evaluation/
├── security/
├── performance/
└── regression/

The intestng is to distinguish between different tests.. 
Unit test
    ↓
Whether the Component works

Integration test
    ↓
Whether the Components work together

Evaluation test
    ↓
Whether the RAG quality is acceptable

Regression test
    ↓
Whether the New change didn't degrade quality

Security test
    ↓
Whether the System doesn't expose/execute unsafe behavior

Performance test
    ↓
Whether the System meets latency/throughput targets
