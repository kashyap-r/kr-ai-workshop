# M0.2-C — Domain Contracts
Added: python/src/rag_platform/domain/contracts.py

## Context

The RAG platform consists of multiple processing stages:
parsing, chunking, embedding, retrieval, reranking and generation.

We need stable boundaries between these stages so implementations can
change independently.

## Goals

- Define clear component responsibilities
- Decouple implementations from consumers
- Enable testing with fake implementations
- Allow different models/strategies to be swapped
- Keep the architecture extensible

## Decision

Use Python `Protocol` to define behavioral contracts.

## Contracts

### Parser

SourceDocument → ParsedDocument

### Chunker

ParsedDocument → DocumentChunk[]

### Embedder

Text[] → Embedding[]

### Retriever

Query → RetrievalResult[]

### Reranker

Query + RetrievalResult[] → RetrievalResult[]

### Generator

Query + Context → Generated response
