 ## Query API Architecture and Decisions 

 The key question here is: 
    What should happen between receiving a user query and returning retrieved chunks?

API Contract 

#### Request 
{
  "query": "What is the company's work from home policy?",
  "top_k": 5
}

Note: top_k is optional 
If omitted, default_top_k = configured value of 5

#### Response Contract 
The response should expose retrieval results, not an artificaially generated answer

{
  "query": "What is the company's work from home policy?",
  "results": [
    {
      "chunk_id": "chunk-123",
      "document_id": "doc-456",
      "text": "Employees may work remotely...",
      "score": 0.8432,
      "metadata": {
        "source": "wfh_policy.md",
        "section": "Remote Work"
      }
    }
  ]
}

Potentially: 
{
  "query": "...",
  "results": [...],
  "result_count": 5,
  "latency_ms": 42.7
}

Note:  DO NOT EXPOSE Intternal implementation details such as...
embedding_model
vector_database
index_file
internal paths
through the public API
